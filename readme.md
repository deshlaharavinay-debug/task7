# Laundry Website

A responsive laundry service website built using HTML5 and CSS3.

## Features
- Responsive navigation bar
- Laundry service hero section
- Call-to-action button
- Responsive laundry image
- Flexbox-based responsive layout
- Tablet and mobile media queries

## Technologies
- HTML5
- CSS3
- Flexbox
- Media Queries

## Purpose
This project was created to practice CSS layout, Flexbox, viewport units, positioning, and responsive web design.
